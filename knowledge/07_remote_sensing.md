# 遥感分析

## 适用场景

- 多波段遥感影像的指数计算（NDVI/NDWI/NDBI/EVI 等）
- 植被覆盖度、水体提取、建筑用地识别
- 遥感影像分类（监督/非监督）
- 土地利用/土地覆盖变化检测
- 影像增强、假彩色合成
- 遥感数据与 GIS 矢量数据叠加分析
- 用户要求"算植被指数""提取水体""做土地分类""变化检测"

## 输入数据要求

- 多波段 GeoTIFF 影像（Landsat 5/7/8/9、Sentinel-2、MODIS 等）
- 必须包含地理参考（transform + CRS）
- 波段顺序和编号需明确（不同传感器波段编号不同）
- 建议使用地表反射率产品（SR）而非原始 DN 值
- 云覆盖应尽量少（云污染会影响指数计算）
- 多时相分析需要不同时相影像已配准（空间配准）

## 分析思路

遥感分析的核心是"地物的光谱特征"。不同地物在不同波段的反射率不同，通过波段运算可以增强特定地物信息。

分析决策流程：
1. **目标地物是什么？** 植被/水体/建筑/土壤 → 选择对应指数
2. **数据是什么传感器？** 确定波段编号（红、近红外、短波红外等）
3. **单时相还是多时相？** 单时相做分类/提取，多时相做变化检测
4. **需要多高精度？** 指数图（快速）vs 分类图（详细）vs 变化检测（对比）

## 处理流程

```
1. 数据准备
   ├─ 上传 GeoTIFF → 自动渲染为底图
   ├─ execute_python：rasterio.open 读取元数据（波段数、尺寸、CRS、nodata）
   ├─ 确认波段编号和对应光谱波段
   └─ 云掩膜（如有 QA 波段，用 execute_python 提取云像素并掩膜）

2. 指数计算
   ├─ NDVI → ndvi_analysis(layer_name, red_band, nir_band)
   ├─ 其他指数（NDWI/NDBI/EVI/NDMI/BSI）→ execute_python 波段运算
   ├─ 批量计算多个指数 → 一次 execute_python 完成
   └─ 每个指数保存为单独 GeoTIFF 或 PNG

3. 阈值分割与地物提取
   ├─ execute_python：np.where(ndvi > 0.3, 1, 0) 提取植被
   ├─ Otsu 自动阈值（skimage.filters.threshold_otsu）
   └─ 提取结果矢量化 → rasterio.features.shapes → GeoJSON 图层

4. 影像分类
   ├─ 非监督分类：KMeans（sklearn）→ 聚类后人工解译类别
   ├─ 监督分类：RandomForest（sklearn）→ 需要训练样本
   ├─ 训练样本来源：用户提供的矢量 ROI 或手动选择
   └─ 分类结果 → 栅格 + 矢量化 + 精度评估（混淆矩阵）

5. 变化检测
   ├─ 两个时相的同一指数相减（如 NDVI_2020 - NDVI_2010）
   ├─ 差值阈值分割 → 变化/未变化区域
   ├─ 分类后比较：分别分类再对比类别变化
   └─ 结果：变化面积统计 + 变化区域矢量

6. 结果展示与解释
   ├─ 指数图：plt.imshow + colorbar（NDVI 用 RdYlGn，NDWI 用 Blues）
   ├─ 分类图：离散色带 + 图例
   ├─ 变化图：红-绿双向色带（增加/减少）
   ├─ 面积统计：各类别像元数 × 像元面积
   └─ 文字解释：植被覆盖度、水体面积、变化趋势
```

## 方法选择依据

### 常用遥感指数

| 指数 | 公式 | 用途 | 阈值参考 |
|------|------|------|---------|
| NDVI | (NIR-Red)/(NIR+Red) | 植被覆盖/长势 | >0.3 有植被，>0.6 茂密 |
| NDWI | (Green-NIR)/(Green+NIR) | 水体提取 | >0.2 水体（McFeeters） |
| MNDWI | (Green-SWIR)/(Green+SWIR) | 建筑区水体（抗建筑干扰） | >0.2 水体 |
| NDBI | (SWIR-NIR)/(SWIR+NIR) | 建筑用地 | >0 建筑（需结合 NDVI） |
| EVI | 2.5*(NIR-Red)/(NIR+6Red-7.5Blue+1) | 增强植被指数（高覆盖区更敏感） | 同 NDVI |
| NDMI | (NIR-SWIR)/(NIR+SWIR) | 植被含水量 | >0 水分充足 |
| BSI | ((SWIR+Red)-(NIR+Blue))/((SWIR+Red)+(NIR+Blue)) | 裸土指数 | 越高越裸露 |

### 传感器波段对应

| 传感器 | 蓝 | 绿 | 红 | 近红外 | 短波红外1 | 短波红外2 |
|--------|---|---|---|--------|----------|----------|
| Landsat 5/7 | B1 | B2 | B3 | B4 | B5 | B7 |
| Landsat 8/9 | B2 | B3 | B4 | B5 | B6 | B7 |
| Sentinel-2 | B2 | B3 | B4 | B8 | B11 | B12 |

注意：ndvi_analysis 工具默认 red_band=1, nir_band=4（0-indexed），使用 Landsat 8 时需指定 red_band=3, nir_band=4。

### 分类方法选择

| 方法 | 需要训练样本 | 精度 | 速度 | 适用 |
|------|------------|------|------|------|
| KMeans 非监督 | 不需要 | 中 | 快 | 快速探索、无样本 |
| RandomForest 监督 | 需要 | 高 | 中 | 有训练样本、多类别 |
| SVM 监督 | 需要 | 高 | 慢 | 小样本、高维特征 |
| 阈值分割 | 不需要 | 低-中 | 快 | 单指数提取（水体/植被） |

### 变化检测方法

- **图像差值/比值法**：简单快速，适合单指数变化
- **分类后比较法**：精度高，可得到"从X类变Y类"的转换矩阵，但误差累积
- 建议：先做指数差值快速定位变化区，再对变化区做分类后比较

## 输出结果

- 指数图：GeoTIFF（保留地理参考）+ PNG 可视化（带 colorbar）
- 分类图：GeoTIFF（整型类别）+ 矢量（矢量化后加载到地图）+ 分类统计表
- 变化检测：差值图 + 变化区域矢量 + 面积变化统计
- Agent 应说明：数据源和时相、使用的指数/方法、关键阈值/参数、主要发现（植被覆盖度、水体面积、变化方向和幅度）、局限性（云污染、混合像元、季节差异）

## 常见问题

### Q1：NDVI 结果范围不在 [-1, 1]
- 原因：使用了原始 DN 值而非反射率，或波段编号错误
- 解决：确认数据是地表反射率产品；检查波段编号；NoData 像素会产生异常值，需掩膜

### Q2：ndvi_analysis 结果全是 0 或 NaN
- 原因：red_band / nir_band 参数错误，指定了不存在的波段
- 解决：先 execute_python 打印 src.count 和各波段统计；Landsat 8 红=B4(index 3)，近红外=B5(index 4)

### Q3：水体提取把阴影也当成了水体
- 原因：NDWI 在阴影区也为正值（阴影的 NIR 反射率低）
- 解决：用 MNDWI 替代 NDWI（SWIR 对阴影不敏感）；或结合 DEM 坡度排除山区阴影

### Q4：分类结果出现椒盐噪声
- 原因：逐像元分类无空间约束，高空间分辨率影像常见
- 解决：分类后做形态学滤波（scipy.ndimage 中值滤波/开闭运算）；或用面向对象分类（先分割再分类）

### Q5：多时相变化检测结果受季节影响大
- 原因：不同时相的物候差异（如 1 月 vs 7 月的 NDVI 差异是季节变化而非土地变化）
- 解决：选择同季节（同月或相邻月）的影像；或用物候标准化方法

### Q6：分类精度怎么评估
- 解决：需要验证样本（独立于训练样本），计算混淆矩阵、总体精度、Kappa 系数；execute_python 用 sklearn.metrics 实现；无验证样本时只能做定性描述，不能声称精度
