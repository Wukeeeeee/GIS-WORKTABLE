# 默认保护迁移：数据流与缺口

## 改造前数据流（按实际调用链审查）

- 导入、绘制、编辑和工程恢复最终进入 `backend/services/tools.py` 的注册表；注册对象同时包含 GeoJSON/栅格资源路径、真实图层名及属性。
- 普通聊天由 `backend/services/graph.py` 路由到 `ai_service.py`，自动上下文会读取图层名称、范围、字段和属性样例；历史、技能、附件及工具结果可并入消息。普通/流式路径都依赖该路由与模型适配器。
- 工具执行可追加图层、地图操作、图片及任务产物。默认工具集中包含 `execute_python`。其子进程没有文件、网络或内存隔离；只按变量名过滤一部分凭据。代码、日志及输出仍可能接触本机可读数据。
- 浏览器本地展示图层和操作；聊天消息可能包含 Markdown 链接/图片及历史内容。保护路径目前禁用了图片自动预览，但保护只在显式敏感标志或会话标记存在时启用。
- 地图默认向 Bing 中国区请求瓦片；自动缩放到图层范围会让底图服务推知粗略视野，但不会将浏览器 GeoJSON 属性随瓦片请求上传。在线 XYZ/WMS/分析服务是独立出站边界。
- 工程保存与恢复携带 `sensitive`，但老工程 `false`/缺省仍可作为未保护注册；前端同步也携带该字段。

## 改造前已确认缺口

1. `workspace_protected()` 只要找不到 `sensitive=true` 就返回 false；新注册默认 false，工程恢复把缺省值变成 false。
2. 受保护 AI 工具目前只有目录、缓冲、点距、排名；筛选/统计/叠加/空间选择/样式/标签尚未接入代号接口。
3. 字段同名映射会被后一个图层覆盖；对象更新时稳定 `layer_id` 会让旧要素代号可能指向新版本要素。
4. 私有映射仅驻内存；重启后 marker 会继续阻止普通路由，但旧代号无法恢复。任意自由文本秘密识别不在本机制范围。
5. `execute_python` 不是安全沙箱，不能放入云端可调用的受保护工具集。
6. 本地解码后内容只能在受信任前端展示；任何转发、分享、导出或被用户再次粘贴仍可能外发。

## 本轮处理与仍有限制

- 注册与恢复时缺省或旧 `false` 均迁移为受保护，前端同步只能升级保护不能降级；图层面板不再提供保护开关。
- 受保护云端工具只接受不透明引用。本轮接入目录、缓冲、距离、排序/排名、筛选、汇总、空间选择/关联、裁剪/相交/合并/差异、样式、标签和地图缩放；原值与完整结果留在本地。
- 多图层同名字段可由明确的“图层名的字段名”在本地解析；仍歧义、缺失或过期引用会停下，不猜对象。编辑/重命名/重注册/工程恢复轮换注册版本；重启后映射重新生成。
- 任意 Python 不进入受保护工具清单；普通模型调用和回退不会接管受保护请求。原文/图片的云端阅读当前拒绝，未实现授权流程。
- 保护边界是模型请求，不等于所有网络请求。本地图层自动缩放可能让 Bing 瓦片服务看到粗略视野；可切换本地白底避免瓦片请求。未登记的新自由文本秘密仍可能无法识别。
- 公网部署时，“本地”指运行后端的服务器；数据会到达该服务器。
