# GIS AI 默认数据保护

所有矢量、栅格及分析结果图层默认使用受保护的 AI 操作流程。新图层、旧工程中的 `true`、`false` 和缺失标记统一迁移为受保护；前端同步和旧任务不能关闭保护。图层菜单不再提供逐层保护开关。

## 工作方式

云端模型只负责理解意图并编排本地工具。发给模型的是随机代号、字段类型、固定状态和结果代号。名称、坐标、几何、路径和属性由后端处理；完整图层和统计结果不会加入后续模型上下文。模型可用接口包括目录、缓冲、点间测地线距离、数值排序/排名、属性筛选、数值统计、空间选择/关联、裁剪/相交/合并/差异、分级/分类设色、标签及缩放到图层。

字段目录目前只提供类型（数值/文本/其他），不提供自动推断的字段业务含义或样本值。用户若要求“经济字段”等语义，而字段名称本身无法唯一映射，需显式写出图层名和字段名；不让另一个云端模型读取样本来猜字段用途。

工程或会话恢复后重新建立代号映射。编辑或重新注册图层会使相关旧代号失效；重启后映射也会重新生成。遇到歧义或失效代号时，操作应停止，不猜测真实对象。任意 Python、任意代码执行、联网检索、原始附件/截图解释及未加入本地接口的能力不会在受保护工作流中调用。需要云端阅读原始文本、属性明细或图片的任务暂不支持；首版没有伪装成授权的开关。

## 数据边界

“本地”指实际运行后端的机器。如果后端部署在公网，真实数据仍会到达该服务器。此机制在后端进程内隔离结构化 GIS 数据，不保护已被控制的后端、本机管理员、工程磁盘文件，也不阻止用户主动复制或再次发送本地展示内容。

当前默认底图使用 Bing 中国区瓦片服务。地图服务只收到当前视野所需的瓦片坐标，不会随瓦片请求收到浏览器中的 GeoJSON 属性表；但自动缩放到图层范围会让服务推知大致区域，反复平移/缩放也会暴露浏览视野。若该范围也敏感，可在“视图 → 底图”切换到本地白底；白底不发瓦片请求。用户接入的在线 XYZ/WMS/在线分析服务仍按其 URL 和服务协议通信，不属于模型代号边界。

已知字段和值替换不是通用的自由文本秘密识别。用户在指令里额外粘贴、改写、拆分或编码的新秘密可能无法识别。代号、类型和操作意图仍会透露有限信息；不承诺绝对防泄漏或不可重新识别的匿名化。

## 本地静态加密与外发审计

工程索引、工程元数据、矢量数据块、工程内栅格资源、普通聊天历史和任务元数据/代码在本机磁盘上使用分块 AES-GCM 加密；新密钥放在操作系统密钥库中，不与密文并排保存。旧格式在成功读取时迁移。运行中的后端必须解密数据才能执行 GIS 操作；栅格资源会临时解密到本机私有临时目录，并在应用正常退出时清理。密钥库不可用或密文校验失败时，不会改用普通明文写入。

用户主动导出的 `.giswork` 工程包是可移植的明文归档，接收者可以读取其中的图层和聊天内容。上传缓存、通用分析输出、任务产物文件和异常退出遗留的临时解密文件尚未全部纳入静态加密；应视为本机可读文件。文件大小、时间戳和矢量 Blob 的内容摘要文件名等元信息仍可见。系统密钥库保护的是静态密钥，不防止当前 Windows 用户、管理员、被攻陷的运行进程或已解锁的操作系统读取数据。更换操作系统账户、重装系统或丢失系统密钥库可能使本地密文不可恢复；应保留用户控制的备份。

“设置 → 日志导出”显示 AI 请求审计。记录包含目标主机、模型、消息/工具数量、类别和请求状态，不记录提示词、坐标、属性值或密钥。`已通过本机检查，准备发送` 表示客户端在网络调用前通过边界检查；`已收到模型服务响应` 说明服务端已处理并返回响应；请求失败或超时时，客户端不能断定请求有没有到达。审计记录保存在本机，可能被有权限访问本机文件的用户修改，不能证明服务商是否留存请求，也不审计底图瓦片和在线数据服务。

## 原文授权（当前未实现）

需要云端理解原始文本、属性明细或图片的任务当前拒绝处理。后续若实现，方案应先在本地生成不可变预览，列出确切内容、用途和目标服务；许可绑定目标、内容摘要、字段/记录范围及请求 ID，并在发送前一次性消费。任何内容或范围变化都需重新预览授权；拒绝、取消、超时、失败和完成都使许可失效。普通历史、工具调用、模型回退、重试和其他请求不得读取或复用许可。

## 失败行为与边界

- 模型请求和工具调用失败时，不回退到普通聊天、不自动重试原文，也不转交另一个模型。
- 同名字段可通过明确的“图层名的字段名”形式在本地解析；未消除歧义时，请求会在发往模型前停止。失效代号或重复要素名不能被猜测匹配。
- 受保护流程不读取普通历史、任务代码、附件或截图作为模型上下文；回复以纯文字展示，避免恢复后的文本通过模型生成链接/图片回送。
- `execute_python` 的实际子进程可访问后端机器上的文件、进程可见资源和网络；凭据名称过滤与 AST 检查不是隔离。因此它不会提供给受保护流程。
- 旧工程的历史聊天仍可能在本地包含原文。重新打开后不把它交给受保护模型，但磁盘文件本身未加密。

## 验证

`backend/tests/test_privacy_mode.py` 使用标记合成数据，经真实模型请求序列化适配器捕获请求；本地 GeoPandas/pyproj 检查真实计算。在线模型验证需单独使用合成数据，本项目当前自动化模拟不代表在线模型或生产服务器验收。浏览器验收范围和截图证据记录在 `artifacts/privacy-mode-20261029/validation.md`。
