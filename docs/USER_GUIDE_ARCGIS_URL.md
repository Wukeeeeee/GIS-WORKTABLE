# ArcGIS REST 矢量数据获取

从首页“公开数据获取”点击“输入地址”或“试用样例”，即可打开 ArcGIS REST 输入框；也可从“数据 → 数据源连接器 → 设置 → 地理服务 → 添加在线数据”进入。粘贴公开 FeatureServer 或 MapServer 地址，点击“检查图层”查看图层与服务限制；服务包含多个图层时，填写目标图层 ID 后再次检查。

检查完成后，先确认图层名称、几何类型、坐标系、对象 ID、单次返回上限和分页能力；字段列表默认折叠，可展开查看。服务根地址返回多个图层时，先查看图层名称与 ID，填写目标 ID 后再次检查。

完整获取样例使用 `https://sampleserver6.arcgisonline.com/arcgis/rest/services/Census/MapServer` 的图层 `2`，并过滤 `STATE_NAME = 'Alabama'`。它用于演示获取与检查流程，属性年代较旧，不应当作当前人口数据或业务分析输入；可直接替换成自己的服务 URL、图层和条件。

选择“限量预览”可先取最多 1,000 条并加载到地图。预览只说明返回样本，不检查源数据完整性。选择“获取全部匹配数据”时，服务先返回匹配对象 ID，再按服务记录上限分批获取；界面显示已获取数量。完整状态仅在获取前后 ID 清单一致、无缺失和重复且返回数一致时标记为完整。服务不支持 ID 清单、请求失败或源清单变化时，任务失败或完整性标记为未知/部分，不会把单页结果说成全量。

默认输出 GeoJSON，完成后尝试加载到地图，并提供数据、获取报告、来源清单和获取配方下载。报告说明查询条件、时间、数量、CRS、检查结果、许可未知状态和 SHA-256。哈希用于核对文件内容，不证明属性正确或分析方法正确；ID 清单稳定也不构成源服务事务快照，获取期间属性仍可能变化。

四个下载链接均返回附件，JSON 来源清单和配方也会保存为文件；地图仍单独读取 GeoJSON。下载后可用 QGIS/GDAL 独立检查数量、字段、CRS 和范围，再将本地数据文件的 SHA-256 与来源清单中的 `output.sha256` 比较。哈希相同只说明文件内容与清单记录一致。

最近一次配方会保存在当前浏览器的本地存储，可通过“重跑上次配方”再次执行；来源 URL 中的 token、key、password、secret、auth、credential 和 signature 参数会从配方、报告及历史记录中移除。因此需要凭据的服务，脱敏配方可能无法自行重新认证，请重新输入有效 URL。配方不保存源数据快照；源服务更新后重跑得到的是新的结果。

重跑会先把上次的地址、图层、模式和过滤条件恢复到表单，便于核对实际执行的查询；任务进行中不能重复启动。

全量获取默认最多 100,000 条，服务端硬上限 1,000,000 条。超过限制请缩小范围或增加过滤条件。空间范围格式为 `minx,miny,maxx,maxy`，按 WGS84 经度/纬度传递；它用于服务端相交筛选，不会裁剪要素几何。

当前获取过程在单机服务进程内执行；关闭服务会中断任务。取消请求会在当前 HTTP 请求结束后、开始下一批前生效。数据源的可用性、速率限制、许可及授权由源服务决定；报告中的许可未知需要使用者自行核对。
