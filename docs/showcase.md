## 项目介绍草稿

GIS WorkTable 是结合自然语言 AI Agent 与手动工具的开源 GIS 工作台。它把空间数据接入、分析、2D/3D 展示和结果导出串成可检查的工作流，让用户能通过交互面板或自然语言完成任务，并核对图层与文件产物。项目采用 FastAPI、LangGraph、Leaflet 和 CesiumJS，项目代码按根目录 MIT License 开放；第三方依赖、服务和数据遵循各自条款。

## 建议演示流程

| 环节 | 操作 | 需要展示的证据 |
| --- | --- | --- |
| 核心演示流程 | 导入可公开分发的本地 GIS 数据 → 缓冲 → 检查结果 → 保存并重新打开工程 | 输入 CRS、距离单位、结果图层和工程恢复；优先采用已验收路径 |
| AI 任务编排（选演） | 对相同图层用自然语言执行分析 | 展示工具、参数与结果；标明需要配置模型服务，不把模拟测试说成真实模型验收 |
| 2D/3D 与扩展接口（选演） | 展示共享图层状态、工具注册或 MCP 接入 | 只展示本次固定提交中可现场复现的能力 |

使用小规模、已授权的数据准备可重复演示，并为网络不可用、模型服务失败准备手动本地流程。首次录制前验证输入数据实际包含在演示材料中；当前 `frontend/samples/` 只有说明文档被 Git 跟踪，不能假定示例 GeoJSON 会随克隆提供。

## 可突出、需要证据支持的设计

- 手动与 AI 调用复用工具和产物通道：展示一次两种入口的相同分析。
- 2D/3D 共享图层状态：展示显隐、选中和图层更新的同步。
- 结果产物检查：展示检查实际覆盖的文件/图层与失败提示，不能将其宣传为结果准确性保证。
- GIS 知识、工具、目录与 MCP 组合：解释具体代码和集成方式，避免未经检索的“首创”表述。
