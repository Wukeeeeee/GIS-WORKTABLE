## 项目介绍草稿

GIS WorkTable 是结合自然语言 AI Agent 与手动工具的开源 GIS 工作台。它把空间数据接入、分析、2D/3D 展示和结果导出串成可检查的工作流，让用户能通过交互面板或自然语言完成任务，并核对图层与文件产物。项目采用 FastAPI、LangGraph、Leaflet 和 CesiumJS，源码以 AGPL v3 开放。

## 建议演示流程

| 环节 | 操作 | 需要展示的证据 |
| --- | --- | --- |
| 手动基础工作流 | 导入可公开分发的 GeoJSON → 缓冲 → 属性检查 → 导出 | 输入 CRS、单位、结果文件与处理历史 |
| AI 任务编排 | 对相同图层用自然语言执行分析 | 工具名、参数、结果图层，避免只展示聊天回复 |
| 2D/3D 联动 | 切换视图、调整显隐与样式、展示面拉伸 | 同一图层身份和数据，明确拉伸不等于真实地形 |
| 开源互通 | 展示工具注册、测试与 MCP 接入 | 源码位置、可复现命令和实际客户端调用 |

使用小规模、已授权的数据准备可重复演示，并为网络不可用、模型服务失败准备手动本地流程。首次录制前验证输入数据实际包含在演示材料中；当前 `frontend/samples/` 只有说明文档被 Git 跟踪，不能假定示例 GeoJSON 会随克隆提供。

## 可突出、需要证据支持的设计

- 手动与 AI 调用复用工具和产物通道：展示一次两种入口的相同分析。
- 2D/3D 共享图层状态：展示显隐、选中和图层更新的同步。
- 结果产物检查：展示检查实际覆盖的文件/图层与失败提示，不能将其宣传为结果准确性保证。
- GIS 知识、工具、目录与 MCP 组合：解释具体代码和集成方式，避免未经检索的“首创”表述。
