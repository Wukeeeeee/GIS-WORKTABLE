## 浏览器实际操作

在临时验证页使用项目调试面板中的矩形和点样例，未调用模型。

| 操作 | 观察到的结果 |
| --- | --- |
| 缓冲区，500 米 | 返回一个新图层，含两个要素，地图实际显示 |
| 用原面图层裁剪缓冲区 | 返回裁剪图层，含两个要素 |
| 叠置相交 | 返回四条属性组合；旧服务出现重复面积累计，已在源码与回归测试中修复 |
| 提取质心 | 返回两个点要素 |
| 属性选择 `val > 15` | 从两个要素中筛出一个 |
| 字段统计，值为 10、20 | 最小值 10、最大值 20、平均值 15、总和 30 |
| 点图层核密度 | 5 个输入点生成 50×50 网格，返回 2500 个格点；结果保留在统计面板 |
| WGS-84 → Web Mercator | 输入 `116.3,39.8`，返回 `12946456.779258,4836921.246400` |

界面验证包括：空间分析窗口实际拖动右下角调整宽高；320px 宽度下标签全部换行可见；折叠隐藏调整控件、展开保留参数；空间统计、栅格和网络窗口通过方向键调整宽度；缺少图层时面板给出提示；窗口中无 SVG 元素。
