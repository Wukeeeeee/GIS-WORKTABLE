# 界面规范

工作台及已有工具界面共用 `frontend/css/workspace.css` 的样式，不为单个模块新增强调色、独立按钮风格或另一套窗口外观。图标可用内联 SVG 或 PNG 遮罩（`.ui-icon`），两者都以 `currentColor` 继承文字颜色；不使用外部 SVG 文件引用与 SVG data URI。

## 视觉

- 界面使用黑白灰；地图影像、数据专题色和必要的错误状态保留其实际含义。
- 点图层默认使用直径 12px 的实心数据色圆点与 1.5px 白色描边，在卫星影像上保持可辨识。图层列表色块与地图填充色同步；分类和分级符号也保留白边，用户设置的大小与透明度仍有效。点符号不继承面图层的默认填充透明度。
- 背景、文字、边框使用公共 CSS 变量。浅色和深色主题共用组件结构。
- 浮动面板和弹窗统一采用 12px 圆角、细边框和轻阴影，标题字号 13px。
- 标题栏控件采用 28px 按钮。图标两种实现都可用：内联 SVG（`stroke="currentColor"`）或用公共 `.ui-icon` 样式加载 PNG 遮罩，两者都继承文字颜色、都适配深浅主题；不引入外部 SVG 文件引用与 SVG data URI。执行按钮使用黑白反色，表单使用统一边框和 6px 圆角。
- Logo 使用 PNG 保留原有构图；地图矢量和填充图案使用 Canvas，避免生成 SVG 图形元素。位置识别弹窗使用纯文本、统一中性色和公共按钮样式。

## 面板交互

- 数据、图层、处理和 AI 入口统一位于左侧竖向导航栏。AI 默认收起，与其它侧面板共用位置和宽度；切换时不清空聊天，标题栏可收起面板。
- 侧面板与地图之间提供可拖动分隔条；调整宽度后更新地图尺寸并记住宽度。支持左右方向键调整、双击或 Home 恢复默认宽度；关闭侧面板后地图占用释放的空间。
- 数据入口集中提供全球数据、本地导入与检索；协议分类保留在检索筛选中，不在工作台重复列出。全球数据地图在中央工作区打开，返回时保留原地图、图层和聊天。
- 左侧数据、图层、处理面板通过标题栏关闭，通过竖向导航恢复。
- 图层列表分两行显示名称、几何类型与要素数；显隐和检查保留直接入口，AI 分析、卷帘、导出、重命名及删除集中在“更多”菜单。长名称省略显示，悬停提供全名。
- 地图快捷控件使用底部横向工具条；窄窗口允许横向滚动，不隐藏已有操作。
- 分析、历史、书签及调试等浮动面板提供“−”折叠和“×”关闭。折叠仅隐藏内容，不重置输入或清空结果。
- 关闭后仍可从原入口重新打开；关闭行为调用模块自己的清理逻辑，与删除图层、清空历史分开。
- 设置、数据目录和属性检查等弹窗保留明确的关闭入口。
- 面板定位使用 `GIS.workspace.centerPanel` / `clampPanel`，依据地图和 AI 的实际可见边界避让，避免写死侧栏宽度。
- 折叠展开、窗口缩放及拖动后，标题栏和关闭按钮应保持可见。
- 通过公共 `preparePanel` 接入的工具窗口在右下角提供调宽高入口，支持拖动、方向键调整和双击恢复。窄窗口的工具标签换行展示，不能裁掉标签或隐藏滚动提示。
- 中文正文和标题共用系统中文无衬线字体；选项名称保持简短，解释放在字段下方。避免在标题中使用“直连”等实现术语。
- 空间分析、空间统计和栅格工具的计算状态与结果显示在当前面板中，运行期间禁用重复提交。没有图层产物时使用“结果已返回”，不能只凭 HTTP 请求结束宣称分析成功。
- 经纬度放在工作台底部状态栏，2D 与 3D 使用同一位置。

## 新增工具时检查

使用 `GIS.workspace.preparePanel` 接入统一标题栏控件。在真实页面检查展开、折叠、关闭、重新打开，以及 AI 展开时的定位；验证折叠前后的输入保持一致。

## 参考设计与独立表达

曾参考用户提供的 GeoLibre 界面截图和其公开用户指南，学习地图为主、手动操作可发现等通用交互。当前调整保留 GIS WorkTable 标识的构图，以 PNG 展示；保留黑白灰组件和已有功能，以自身的数据获取与分析流程组织入口。

| 参考截图中的组织 | 当前工作台的组织 |
| --- | --- |
| 左侧竖向浏览器、图层等导航 | 左侧数据、图层、处理、AI 导航，共用可调宽侧面板 |
| 在线服务按协议分级树展示 | 全球数据获取卡片和目录检索；协议作为筛选条件 |
| 地图右侧竖排快捷控件 | 地图底部横向工具条 |

以上仅说明对所提供截图的视觉对照与当前设计选择，不代表对 GeoLibre 全部界面、代码、素材许可证或赛事原创性要求的完整审核。通用图标与布局相似不能单独用于判断授权或侵权；复用第三方代码、图标、字体和数据时，应记录具体版本、来源及许可证，按赛事要求披露参考和团队贡献。
